# Jay Noir artist site

Static cinematic site with a Vercel serverless subscribe endpoint.

## Email setup
Create a Supabase table:

```sql
create table if not exists jay_noir_subscribers (
  id bigint generated by default as identity primary key,
  email text unique not null,
  source text default 'website',
  created_at timestamptz default now()
);
```

Set Vercel env vars `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`.
