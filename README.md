# Jay Noir

Official Jay Noir artist site.

The current build uses the supplied full-resolution Jay Noir photos across the hero, editorial gallery, music visual, inner-circle scene, and about section.

## Email storage setup

Create a dedicated Supabase project, then run:

```sql
create table if not exists public.jay_noir_subscribers (
  id bigint generated by default as identity primary key,
  email text unique not null,
  source text not null default 'website',
  consented_at timestamptz not null,
  created_at timestamptz not null default now()
);

alter table public.jay_noir_subscribers enable row level security;
```

Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY` in Vercel. The service-role key must stay only in Vercel's server environment; never put it in the HTML or browser JavaScript.

Live deployment is handled through Vercel.
